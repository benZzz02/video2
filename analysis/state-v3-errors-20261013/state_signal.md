## 只在可观测的 Recent-only Response 子集上检查提高阈值

## 判断与限制

提高阈值可以作为独立验证集上的后续对照，但这里不能把它当成已经得到的修复。高概率 Response 仍包含历史可修复的错误；负答案经常停留在 Silence，而计数题经常 Response 后仍答错。信号混合了任务语义、是否愿意回答和证据充分性，不是统一校准的历史需求分数。

较高阈值在可观测子集上的收益伴随大比例退回 fill；必须同时检查 RT 历史干扰、BT/FT 缺失历史和调用成本。不得用本测试集选择阈值再将相同数据作为改进证据。

未观测到的首轮非 Response 的 Recent-only 答案、中间预算的答案、以及早停后更大预算的状态均未估计。JSON 记录了固定分箱、各任务阈值表、精确样本集合、配对统计、典型样本 ID 与源文件 SHA-256，便于复核。
