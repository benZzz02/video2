# OneStreamer 视觉记忆实验结果汇总（OVO-Bench，3,035 题）

模型均为冻结的 OneStreamer-4B，128K 上下文。分数由 `summarize_runs.py` 从各次运行的逐题预测重新计算
（官方口径：BT/RT/FT 内先平均子任务，再平均三类），机器可读版本为 `full_run_scores.json`。
各次运行自带的 `summary.json` 在 `run_summaries/`（官方 Recent16 输出没有 summary，分数见 json）。
逐题预测（gzip 压缩，含原始输出、历史时间戳、近期帧时间戳等字段）在 `predictions/`，
在仓库根目录运行 `python analysis/results-summary-20261017/summarize_runs.py` 即可复现下表。

说明：

- **Fill**：历史存储固定 16K token，高分辨率视频只保留最近约 23–90 秒；近期帧比官方晚约 1 秒。
- **Frame-ID 原计分**：解析器把没有 `ANSWER:` 前缀的答案记为空，分数偏低是计分 bug；重算行用官方解析器处理原始输出。
- **全上下文 v2**：历史预算按上下文剩余计算（超出时先压缩、再均匀抽稀），近期帧与官方对齐。
  EPM、OJR、REC 高于 Fill；ASI、CRR、ACR、OCR 低于 Fill。

## 按问题选择读取范围（离线拼接）

详见 `../question-router-20261016/README.md`。模型只读问题文字判断 NOW / SHORT / LONG，
判为 NOW 的题再用官方 Recent16 作答的首 token 概率做画面检查（τ=0.80，低于则读最近一段历史）。
